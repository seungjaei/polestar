# 웹사이트 수정 요구사항 정의서 (Mobile / PC 분리 최종본)

---

## 0. 공통 개발 환경 및 인프라 구축 요구사항

* **Supabase DB 연동 및 테이블 설계:**
  * 회원 정보(`users`: 휴대폰 번호, 마케팅 수신 동의 여부), 장바구니 데이터(`cart_items`: 상품 ID, 옵션[사이즈/컬러], 수량, 선택 상태), 주문/배송 데이터(`orders`: 배송 상태, 결제 정보) 저장을 위한 Supabase 데이터베이스 테이블을 구성하고 RLS(Row Level Security) 및 API 연동을 진행합니다.
* **GitHub 배포 및 최후 제출:**
  * 모든 수정 작업 완료 후 테스트를 거친 최신 코드를 지정된 GitHub 리포지토리에 푸시(Push)하고, 최하단에 접근 가능한 **GitHub 저장소 링크**를 작성하여 제출합니다.

## 1. PC (Desktop) 버전 수정사항

### **[1-1] 팝업창 스크롤바 버그 수정**
* **현상:** 팝업창을 닫아도 화면에 팝업용 스크롤바 잔상이 남아있는 현상 발생.
* **요청:** 
  * 팝업창에 있는 스크롤바가 완전히 제거/사라지도록 수정.
  * 팝업 내부 및 바깥 영역에 불필요한 스크롤바가 노출되지 않도록 CSS/JS 처리 (`overflow` 제어 로직 재정비).

### **[1-2] 헤더 디자인 및 스크롤 동작 수정**
* **헤더 배경색:** 헤더의 상질감을 줄이고 시각적 통합성을 높이기 위해 배경색을 완전한 딥 블랙(`#0a0a0a`)으로 변경합니다.
* **중앙 고정 요소:** 원형 레이아웃 중앙의 `Polestar 로고`와 `스토어 둘러보기` 버튼/텍스트는 회전하지 않도록 정중앙에 고정(Fixed) 처리합니다.
* **부채꼴 브랜드 정렬 및 크기 조정:**
  * 회전하는 브랜드 로고(`libilly`, `blazed`, `i4p`, `iabstudio`)가 부채꼴의 exact center(중앙 위치)에 오도록 좌표 및 회전 축을 재설정합니다.
  * `blazed` 로고는 타 브랜드에 비해 작아 보이므로 기존 대비 **2배(200%) 크기로 확대**하여 visual balance를 맞춥니다.
* **PPT 섹션 헤더 숨김 연출:** 
  * PPT 섹션 전까지는 헤더가 Sticky 상태를 유지하다가, PPT 섹션 영역 진입 시 상단으로 부드럽게 숨겨집니다(`transform: translateY(-100%)`).
  * 스크롤을 다시 위로 올리면 헤더가 원래대로 다시 나타납니다.

### **[1-3] PPT/아티스트 비주얼 및 가독성 개선**
* **아이폰 목업(Mockup) 프레임:** 아티스트 동영상 플레이어 외곽에 아이폰(iPhone) 디바이스 테두리 프레임을 씌워 실제 모바일 기기에서 재생되는 시각 효과를 구현합니다.
* **원페이지 스크롤 (Full-page Snap Scroll):** PPT 섹션 내에서는 마우스 휠 동작 한 번에 한 페이지(슬라이드)씩 딱 맞춰 넘어가도록 Snap Scroll을 연동합니다.
* **텍스트 가독성 최적화:** PPT 섹션 내 아티스트 설명 글꼴의 크기, 줄바꿈, 행간(line-height)을 조절하여 시각적 가독성을 높입니다.

### **[1-4] 회원가입 & 인증 플로우 개선 (독립 페이지)**
* **페이지 라우팅 분리 및 폰트 가독성 최적화:** 
  * 회원가입 화면을 기존 레이어 모달/팝업 방식에서 **독립된 세부 페이지 URL**(`/signup`)로 변경합니다.
  * 기존 모달 대비 레이아웃 확장감을 고려하여, **페이지 내 텍스트 및 폼 요소의 폰트 크기를 화면 가독성에 어울리도록 비례 조정**합니다.
* **인증번호 입력란 생성:** 회원가입 폼 내 `인증번호 발송` 버튼 및 카운트다운 타이머가 포함된 `인증번호 입력 칸`을 생성합니다.
* **도로명주소 API 연동:** [도로명주소 찾기] 버튼 클릭 시 카카오/우체국 우편번호 검색 팝업창이 독립적으로 연결되어 주소가 자동 입력되도록 구현합니다.
* **이메일 인증 절차 제거:** 데모 운영 목적에 맞춰 기존 이메일 인증 절차를 완전 제거하고, **회원가입 완료 즉시 로그인 상태 전환**이 가능하도록 플로우를 간소화합니다.

### **[1-5] 로고 페이지 & 장바구니/결제 프로세스 고도화**
* **로고 정렬 및 네온 효과:**
  * `libilly, blazed, i4p, iabstudio x polestar` 협업 로고 영역에서 'X' 문자가 정확히 정중앙에 위치하도록 가로/세로 레이아웃을 조절합니다.
  * 검정 글씨 등 가독성이 저해되는 부분의 글자에는 **흰색 네온(Text-shadow / Glow) 효과**를 적용합니다.
* **독립된 장바구니 페이지 및 기능 강화 (`/cart`):**
  * 장바구니를 기존 모달 형태에서 **독립 URL 페이지**로 전환하며, **페이지 전체 가독성에 맞춰 텍스트 폰트 크기와 간격을 최적화**합니다.
  * **옵션 변경 기능:** 장바구니 목록 내에서 각 상품의 **사이즈(Size) 및 컬러(Color)**를 드롭다운/모달로 변경하고 실시간으로 반영합니다.
  * **선택/전체 삭제 기능:** 헤더 영역의 전체 선택 체크박스 및 상품별 개별 선택 체크박스를 제공하고, [선택 삭제] 및 [전체 삭제] 기능을 구현합니다.
  * **개별/합계 가격 표시:** 각 상품 카드 옆에 개별 상품 금액(수량 반영)을 명확히 표기하고, 하단에 총 결제 예정 금액을 구분하여 배치합니다.
* **주문/결제 페이지 신설 (`/checkout`):**
  * 장바구니에서 '주문하기' 클릭 시 바로 주문 완료로 넘어가지 않고, 독립된 **[결제/주문 페이지]**로 이동하며 텍스트 크기를 독해하기 적절한 크기로 구성합니다.

  #### 결제 / 주문 페이지 상세 스펙 ####
  * **주문 상품 정보 요약 (Order Summary):** 대표 이미지, 브랜드명, 상품명, 선택 옵션(컬러/사이즈/수량), 개별 금액
  * **배송지 정보 입력 (Shipping Info):** 수령인명, 연락처, 우편번호 검색(도로명주소 API) 및 상세주소, 배송 메모 선택
  * **최종 결제 금액 상세 (Price Breakdown):** 총 상품 금액 + 배송비(특정 금액 이상 무료배송) = 최종 결제 예정 금액
  * **결제 수단 선택 (Payment Methods):** 신용카드, 간편결제, 무통장 입금 등 선택 라디오 버튼 및 테스트 결제 진행 동의 체크박스
  * **CTA 버튼:** [ 000,000원 결제하기 ] 버튼 클릭 시 주문 완료 처리 및 Supabase `orders` 테이블 저장

### **[1-6] 마이페이지 & 고객센터 세부 페이지화 및 기능 확장**
* **독립 세부 페이지 전환 및 타이포그래피 재정비:** 
  * 기존 레이어 모달 방식에서 마이페이지(`/mypage`), 고객센터(`/support`) 등 전용 자식 페이지 URL로 독립 라우팅합니다.
  * 모달 형태에서 풀페이지 형태로 변경됨에 따라, **모든 본문, 타이틀, 안내 텍스트의 폰트 크기를 페이지 레이아웃 가독성에 어울리도록 확대/조정**합니다.
* **회원정보 수정 (Supabase 연동):** 마이페이지 내 **휴대폰 번호 변경** 및 **마케팅 수신 동의/거부 토글 설정** 기능을 제공하고 DB에 실시간 업데이트합니다.
* **배송 상태 조회 시스템:**
  * 주문 내역에서 배송 진행 상황을 5단계 타임라인 UI로 시각화합니다.
  * **배송 단계:** `준비중` ➔ `배송중` ➔ `배달지도착` ➔ `배달중` ➔ `배달완료`

  #### 마이페이지 상세 스펙 ####
  * **프로필 요약:** 회원 이름/이메일, 주문 상태 요약 배지
  * **배송 상태 트래킹:** 최근 주문 내역, 5단계 배송 타임라인, [송장번호 조회], [주문 취소/반품] 버튼
  * **회원 정보 수정:** 휴대폰 번호 수정, 마케팅 수신 동의 토글, 비밀번호 변경/탈퇴
  * **쇼핑 서브 메뉴:** 장바구니 바로가기, 최근 본 상품/위시리스트

  #### 고객센터 페이지 상세 스펙 ####
  * **고객센터 안내:** 대표 CS 번호, 이메일, 운영 시간 안내
  * **자주 묻는 질문 (FAQ):** 카테고리별(`주문/결제`, `배송`, `교환/반품`, `회원`) 아코디언 UI 질문/답변 리스트
  * **1:1 문의하기:** 문의 유형 선택, 제목/내용 작성, 문의 내역 및 답변 상태(`답변 대기`/`답변 완료`) 조회
  * **쇼핑 가이드/정책:** 배송/교환/반품 정책, 이용약관 안내

## 2. Mobile 버전 수정사항

### **[2-1] 모바일 팝업창 UX 개선**
* **배경 터치 닫기 (Dimmed Area Click):** 모바일 팝업 활성화 시 팝업 외의 빈 공간(Dimmed 배경)을 터치하면 팝업 전체가 바로 닫히도록 터치 이벤트를 등록합니다.
* **스크롤바 제거:** 모바일 환경 전체 팝업 및 내부 요소의 스크롤바를 숨김 처리합니다 (`::-webkit-scrollbar { display: none; }` / `scrollbar-width: none;`).

### **[2-2] 모바일 헤더 디자인 및 스크롤 연출**
* **헤더 배경색:** 헤더 전체 배경색을 완전한 `#0a0a0a`로 지정합니다.
* **중앙 고정 요소:** 원형 중앙의 `Polestar 로고` 및 `스토어 둘러보기` 버튼을 중앙에 고정(Fixed) 처리하여 회전 대상에서 제외합니다.
* **부채꼴 브랜드 정렬 및 크기 조정:**
  * 회전 브랜드 로고(`libilly`, `blazed`, `i4p`, `iabstudio`)를 부채꼴 중앙 축에 맞춰 재배치합니다.
  * `blazed` 로고의 크기를 기존 대비 **2배(200%)로 확대**합니다.
* **PPT 섹션 스크롤 연출:** 모바일 스크롤이 PPT 섹션 영역에 도달하면 상단 헤더를 숨겨 본문 가독 면적을 극대화합니다.

### **[2-3] 모바일 PPT/아티스트 영역 레이아웃 및 팝업 재정비**
* **모바일 전용 카드 레이아웃:** 
  * 원형 영역 하단의 PPT 섹션 깨짐 현상을 전체 수정합니다.
  * 아티스트 사진, 이름, 브랜드, 설명 텍스트가 모바일 한 화면(100vh)에 깔끔히 맞춰지도록 여백과 폰트 크기를 조절합니다.
* **타이포그래피 및 가독성:**
  * 문장이 어색하게 끊기지 않고 마침표 단위로 깔끔하게 떨어지도록 `word-break: keep-all` 및 행간을 다듬습니다.
* **동영상 팝업 & 아이폰 프레임 연출:**
  * 아티스트 카드 터치 시 동영상 시청 모달 팝업을 출력합니다.
  * 영상 외곽에 **아이폰 디바이스 프레임**을 씌우고 **음소거 자동 재생(Muted Auto-play)**을 연동합니다.

### **[2-4] 모바일 회원가입 & 인증 플로우 개선**
* **독립 페이지 구현:** 회원가입 화면을 전용 모바일 페이지(`/signup`)로 연결합니다.
* **인증번호 입력란 생성:** `인증번호 발송` 버튼 및 `인증번호 입력 칸`을 제공합니다.
* **도로명주소 API 연동:** [도로명주소 찾기] 터치 시 우편번호 검색 웹뷰/모달을 연동합니다.
* **이메일 인증 절차 제거:** 이메일 인증 절차 없이 **회원가입 완료 즉시 자동 로그인** 상태로 진입하도록 만듭니다.

### **[2-5] 모바일 로고 페이지 & 장바구니/결제 프로세스**
* **로고 정렬 및 네온 효과:**
  * `libilly, blazed, i4p, iabstudio x polestar` 로고의 'X' 문자가 정중앙에 올 수 있도록 정렬을 고칩니다.
  * 시독성이 낮은 텍스트에는 **흰색 네온(Glow) 효과**를 추가합니다.
* **독립된 장바구니 페이지 & 기능 구축 (`/cart`):**
  * 모바일 전용 장바구니 독립 페이지로 연결합니다.
  * 모바일 UI 상에서 **사이즈 및 컬러 옵션 변경** 인터랙션을 연동합니다.
  * **전체 선택 / 개별 선택 / 선택 삭제 / 전체 삭제** 기능을 배치합니다.
  * 각 상품별 개별 금액 및 총 금액을 명확히 분리하여 표시합니다.
* **주문/결제 페이지 전환 (`/checkout`):** '주문하기' 터치 시 모바일 주문/결제 수단 선택 페이지로 연결합니다.

### **[2-6] 모바일 네비게이션 & 마이페이지 확장**
* **세부 페이지 전환:** 마이페이지(`/mypage`) 및 고객센터(`/support`)를 모바일 전용 세부 URL 페이지로 전환합니다.
* **회원정보 수정 (Supabase 연동):** 휴대폰 번호 변경 및 마케팅 수신동의 토글 UI를 구성합니다.
* **배송 상태 트래킹:** 5단계 배송 타임라인 UI (`준비중` ➔ `배송중` ➔ `배달지도착` ➔ `배달중` ➔ `배달완료`)를 모바일 화면에 맞춰 최적화합니다.

## 3. 작업 완료 후 제출 형식
