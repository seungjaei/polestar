[역할 정의]
너는 한국 힙합 아티스트 프로모션 매거진 및 이들의 공식 브랜드 스토어가 집결된 'POLESTAR' 컬처 쇼케이스 웹사이트를 구축하는 수석 프론트엔드 개발자이자 UI/UX 디자이너야.
작업 위치는 `ai_web/lecture1/polestar/` 폴더 내부야.
다음 기획/디자인 가이드 및 세부 요구사항을 모두 충족하는 완결된 프로젝트 코드를 작성하되, HTML, CSS, JavaScript를 각각 분리된 파일로 구조화하여 지정된 폴더에 작성해 줘.

---

### 0. 기획 및 디자인 개요 (Project Planning & Design Strategy)

1. **주제 및 핵심 정체성 (Core Identity):**
   - "POLESTAR는 한국 대표 힙합 아티스트의 음악과 비주얼을 매거진 형태로 아카이빙해 프로모션하고, 그들의 패션 브랜드를 경험 및 구매할 수 있도록 연결하는 종합 컬처 플랫폼입니다."
     이 웹사이트의 핵심 구조는 '아티스트 프로모션(홍보)'과 '브랜드 커머스(판매)'라는 두 가지 역할이 아주 명확하게 나누어져 있으면서도 자연스럽게 연결되는 형태입니다. 기존의 일반적인 온라인 쇼핑몰과 우리 사이트가 어떻게 다른지 세 가지 단계로 풀어 설명하면 다음과 같습니다.

   - 메인페이지의 역할: "아티스트를 경험하는 디지털 매거진"
     보통의 옷가게 웹사이트는 첫 화면부터 "이 옷 얼마입니다, 사세요" 하고 상품 가격표와 구매 버튼을 나열합니다. 하지만 우리 사이트의 메인페이지는 물건을 파는 상점이 아니라 아티스트의 멋과 서사를 보여주는 잡지(Magazine)의 역할을 합니다.
     빈지노, 기리보이, 박재범, 창모라는 힙합 씬의 거장 4인이 현재 어떤 음악적 생각을 하고 있는지, 어떤 비주얼 작업을 하는지 인터랙티브한 영상과 화보로 먼저 보여줍니다.
     방문자는 메인페이지에서 브랜드를 사기 전에 '아티스트라는 인물과 그의 문화'에 깊게 몰입하고 팬심을 느끼게 됩니다.

   - 서브페이지의 역할: "아티스트의 정체성을 소장하는 스토어"
     메인페이지에서 아티스트의 비주얼과 영상에 매료된 방문자가 해당 아티스트를 클릭하면, 비로소 그 아티스트가 만든 공식 브랜드의 서브페이지(스토어)로 이동합니다.
     이곳에서는 아티스트가 직접 디자인하고 참여한 옷(IAB STUDIO, i4p, BLAZED, LIBILLY)의 착장 룩북을 감상하고, 원하는 치수와 옵션을 선택해 실제로 구매까지 진행할 수 있습니다.
     단순히 옷을 사는 것이 아니라, '내가 좋아하는 아티스트의 정체성과 단편을 소장한다'는 경험을 제공합니다.

   - 두 공간을 잇는 전체적인 흐름 (User Journey):
     결국 이 사이트의 전체적인 흐름은 [아티스트의 음악과 비주얼을 감상하며 브랜드에 매료됨(메인페이지)] -> [자연스럽게 그 아티스트의 브랜드 옷을 찾아가 구매함(서브페이지)]의 순서로 이어집니다.
     즉, "아티스트를 홍보하는 무대"와 "그 아티스트의 옷을 파는 상점"이 하나로 합쳐진 독보적인 아티스트 중심의 플랫폼이라고 이해하시면 됩니다.

2. **브랜드 정체성 & 사이트 구축 목적:**
   - **브랜드명:** POLESTAR (폴스타 - 한국 스트릿 서브컬처와 힙합 아티스트를 비추는 북극성)
   - **구축 목적:** 아티스트에 대한 대중적 관심과 팬덤 경험을 끌어올리고(메인페이지의 아티스트 홍보), 나아가 아티스트 브랜드의 제품 구매(서브페이지의 커머스)로 자연스럽게 전환시키는 완성도 높은 아티스트-브랜드 유기적 UX 제공.

3. **디자인 컨셉 & 키워드:**
   - **디자인 컨셉:** "Dark Minimal Hip-Hop Artist Magazine & Interactive Brand Store"
   - **핵심 키워드:** #KoreanHipHopArtist, #ArtistPromotion, #SubcultureMagazine, #DarkMinimal, #ArtistBrandStore

4. **타겟 페르소나 (Target Personas):**
   - **페르소나 A (국내외 힙합 팬덤 & 음악 매니아):** 좋아하는 힙합 아티스트의 최신 비주얼, 디랙팅 스토리, 티저 영상을 감상하고 아티스트의 철학을 경험하려는 유저.
   - **페르소나 B (스트릿 패션 컬렉터 / 20대 남녀):** 아티스트가 직접 착용한 한정판 컬렉션 및 룩북을 확인하고 빠르게 구매하려는 유저.
   - **페르소나 C (서브컬처 에디터/디자이너):** 힙합 아티스트 문화와 결합된 미니멀하고 세련된 웹 UI/UX 및 그래픽 아카이빙을 감상하려는 유저.

### 2. 디자인 스타일 & 타이포그래피 위계 및 z-index 계층 규칙

1. **플랫 UI 규칙 (border-radius / box-shadow 엄격 금지):**
   - 카테고리, 원형 섹션, 아티스트 카드, 버튼, 팝업창, 모달, 폼 요소 등 모든 UI에 라운딩(`border-radius: 0 !important`)과 그림자(`box-shadow: none !important`) 효과를 완전히 제거할 것.
   - 칼같이 떨어지는 다크 매거진 스타일의 플랫(Flat) & 딥 다크 미니멀 레이아웃으로 연출할 것.

2. **폰트 & 시각적 위계질서 (Typography Hierarchy):**
   - **영문 로고 / 타이틀 / 메인 헤딩:** `'Playfair Display', serif`
   - **본문 / UI / 커머스 폼 전체:** `'Pretendard', 'Noto Sans KR', sans-serif`
   - **폰트 사이즈 / 위계 정밀 지정 (웹 가독성 최적화):**
     * 메인 헤더 타이틀: `48px` (`font-weight: 800`, `letter-spacing: -0.02em`)
     * 브랜드 타이틀: `28px` (`font-weight: 700`, `#FFFFFF`)
     * 아티스트 / 디렉터명: `24px` (`font-weight: 700`, Accent Color `#E63946`)
     * 본문 / 한 줄 요약 / 브랜드 소개: `14px` (`font-weight: 400`, `#A0A0A0`, `line-height: 1.7`)
     * 캡션 / 버튼 / 브레드크럼 / 소형 UI: `14px` (`font-weight: 500`, `#888888`)

3. **컬러 팔레트 (HEX 코드):**
   - **Background:** Pitch Black (`#0A0A0A`) (딥 다크 테마)
   - **Text Primary:** White (`#FFFFFF`)
   - **Text Secondary:** Muted Gray (`#888888`)
   - **Accent Point:** Sunset Coral / Neon Accent (`#E63946`) (아티스트 강조, 디렉터명, 버튼 포인트)
   - **Hover Overlay:** Dark Black (`rgba(28, 25, 23, 0.3)`)

4. **1 단위 순차적 z-index 계층구조 (표준 Clean Code 지침):**
   - **`z-index: 1`:** 최하단 백그라운드 슬라이더 / 비디오 오버레이 / 회전 휠 뷰
   - **`z-index: 2`:** 고정 상단 헤더 (Header Bar)
   - **`z-index: 3`:** 메인 하단 혜택 팝업 컨테이너 및 플로팅 TOP 이동 버튼
   - **`z-index: 4`:** 모달 어두운 배경 오버레이 (Modal Backdrop Overlay)
   - **`z-index: 5`:** 유저 세션 모달 본체, 카트 드로어, 옵션 미선택 토스트 메시지

### 3. 메인페이지 접속 시 혜택 팝업창 3종 (Modal Pop-ups)

메인페이지 접속 1초 후, 화면 최하단 좌측부터 중앙 방향으로 3개의 혜택 팝업 카드가 가로로 나란히 등장하는 고정 레이아웃을 적용합니다.

1. **배치 위치 및 화면 규격 (Position & Size Specification):**
   - **노출 시점:** 페이지 로드 완료 후 1초(`1000ms`) 뒤 Fade-in & Slide-up 전환으로 등장.
   - **위치:** 화면 좌측 하단 고정 (`position: fixed; bottom: 30px; left: 40px; z-index: 3; max-width: calc(100vw - 80px); overflow-x: auto;`).
   - **정렬 방식:** 3개의 팝업 카드가 가로 1열로 나란히 배치 (`display: flex; flex-direction: row; gap: 16px;`).
   - **개별 카드 규격:**
     * 너비: `width: 280px; flex-shrink: 0;` (해상도가 좁아지더라도 스크롤로 대응 및 레이아웃 깨짐 방지)
     * 높이: `height: 160px` (메인 화면 컨텐츠를 가리지 않는 슬림한 카드 형태)
     * 배경 및 테두리: Pitch Black (`#0A0A0A`) 배경, Accent Coral (`#E63946`) 1px 테두리 적용.

2. **팝업 공통 인터랙션 및 기능 요구사항:**
   - **플랫 UI 규칙 적용:** `border-radius: 0 !important`, `box-shadow: none !important` (완전한 다크 플랫 매거진 무드 연출).
   - 각 카드 하단/우측 상단에 [오늘 하루 보지 않음] 체크박스/텍스트 버튼과 [X (닫기)] 버튼 제공.
   - [오늘 하루 보지 않음] 클릭 시 `localStorage`를 활용하여 24시간 동안 해당 팝업 카드가 다시 뜨지 않도록 처리.
   - [X (닫기)] 클릭 시 해당 팝업 카드 개별 닫기 처리.
   - 등장/퇴장 트랜지션: `transition: opacity 400ms cubic-bezier(0.16, 1, 0.3, 1), transform 400ms cubic-bezier(0.16, 1, 0.3, 1)`.
     * 숨김 상태: `opacity: 0; transform: translateY(20px); pointer-events: none;`
     * 노출 상태: `opacity: 1; transform: translateY(0); pointer-events: auto;`

3. **팝업창 3종 상세 컨텐츠 (Card Contents):**
   - **[Card 1] RANDOM BOX (아티스트 컬렉션 랜덤 박스):**
     * Subtag: `LIMITED DROP` (`10.4px`, Accent Coral `#E63946`)
     * 타이틀: POLESTAR RANDOM BOX (`16px`, Bold, `#FFFFFF`)
     * 내용: 4대 아티스트 브랜드 시그니처 아이템 랜덤 구성 (`14px`, `#A0A0A0`)
     * 가격/혜택: 150,000 KRW (`18px`, Bold, `#FFFFFF`)
   - **[Card 2] 3+1 SPECIAL EVENT (랜덤 상품 3+1 혜택):**
     * Subtag: `PROMOTION` (`10.4px`, Accent Coral `#E63946`)
     * 타이틀: ARTIST DROPS 3+1 (`16px`, Bold, `#FFFFFF`)
     * 내용: 랜덤박스 3개 구매 시 1개 추가 무료 증정 (`14px`, `#A0A0A0`)
     * 가격/혜택: 3+1 SPECIAL DEAL (`18px`, Bold, `#FFFFFF`)
   - **[Card 3] MILEAGE REWARD (마일리지 적립 혜택):**
     * Subtag: `MEMBERSHIP` (`10.4px`, Accent Coral `#E63946`)
     * 타이틀: HIGH-VALUE REWARD (`16px`, Bold, `#FFFFFF`)
     * 내용: 30만원 이상 구매 시 추가 마일리지 적립 (`14px`, `#A0A0A0`)
     * 가격/혜택: +45,000 M REWARD (`18px`, Bold, `#FFFFFF`)

### 4. 메인페이지 영역별 세부 레이아웃 및 스크롤 흐름 명세 (메인 상품 전시 절대 금지)

★ **중요 원칙:** 메인페이지에는 어떠한 상품 리스트도 직접 전시하거나 배치하지 않습니다. 상품 전시는 원형 메뉴나 브랜드 카드를 통해 이동하는 서브페이지 내에서만 진행합니다.

---

#### [구역 1] 헤더 & 메인 네비게이션 (Header & Navigation Zone)
- **레이아웃:** Fixed Top Layout (`position: fixed; top: 0; left: 0; height: 80px; width: 100%; z-index: 2;`). 스크롤 이동과 관계없이 화면 최상단에 항상 고정 노출됨.
- **스타일:** Glassmorphism 적용 (`backdrop-filter: blur(12px); background: rgba(10, 10, 10, 0.85); border-bottom: 1px solid rgba(255, 255, 255, 0.08);`).
- **로고:** `ai_web/lecture1/polestar/images/logo/polestar1.png` 이미지 로고를 헤더 중앙에 배치 (`height: 34px;`).
- **유저 세션 메뉴 (서브페이지에서만 나오는 메뉴):**
  * **메인페이지 접속 시:** 유저 세션 메뉴(`LOGIN`, `JOIN`, `CART`, `MYPAGE`)를 숨기고 중앙 로고만 깔끔하게 노출하여 매거진 몰입감 극대화.
  * **서브페이지 진입 시:** 헤더 우측에 `LOGIN`, `JOIN`, `CART(0)`, `MYPAGE` 세션 메뉴 바 및 좌측에 현재 위치 브레드크럼(Breadcrumb)이 활성화되어 노출됨.
  * **유저 세션 폰트 규격:** `'Pretendard', sans-serif`, `14px`, `font-weight: 500`, Color `#A0A0A0`, Hover Color `#FFFFFF` (`transition: color 200ms ease`).
  * **브레드크럼 폰트 규격:** `'Pretendard', sans-serif`, `14px`, `font-weight: 400`, Color `#888888`.
- **로고 클릭 인터랙션:** 헤더 로고 클릭 시 SPA 방식으로 메인 첫 페이지(원형 히어로 View)로 리셋 및 스크롤 최상단 이동.

#### [구역 2] 메인 히어로 (원형 인터랙션 휠 + 백그라운드 슬라이더 연동 Zone)
- **영역 규격:** 뷰포트를 가득 채우는 풀스크린 영역 (`height: 100vh; position: relative; overflow: hidden;`).

- **1) 브랜드별 슬라이더 이미지 경로 및 실시간 각도 동기화 Layer (`pointer-events: none; z-index: 1;`):**

### 5. 서브페이지, 상품 상세, 유저 세션 모달 명세 (SPA 방식)

메인페이지의 원형 브랜드를 클릭하면 메인페이지 뷰가 닫히고 서브페이지 전용 View로 정밀한 트랜지션 애니메이션과 함께 전환되어 진입합니다.

★ **직관적인 화면 전환 Flow 및 애니메이션 명세 (SPA View Switching):**
- **화면 전환 애니메이션 수치:** 모든 SPA 뷰 스위칭(메인 ↔ 서브 ↔ 상세)은 `duration: 450ms`, `timing-function: ease-in-out` 속성의 Fade-in/out 및 위치 이동 트랜지션을 적용하여 매끄럽게 전환될 것.
- **브랜드 클릭 시:** 메인페이지 내 브랜드(원형 휠 조각) 클릭 시 ➔ 메인페이지가 닫히고 해당 브랜드 전용 서브페이지(룩북 뷰)로 화면 전환.
- **폴라로이드 상품 클릭 시:** 서브페이지 내 폴라로이드 모델/상품 클릭 시 ➔ 룩북 뷰가 닫히고 독립 상품 상세페이지 뷰로 화면 전환.
- **상단 헤더 로고 클릭 시:** 화면 어디서든 상단 POLESTAR 로고 클릭 시 ➔ 메인 첫 페이지(원형 히어로 뷰)로 리셋 복귀.
- **`[BACK TO LOOKBOOK]` 클릭 시:** 상세페이지 내 버튼 클릭 시 ➔ 해당 브랜드의 룩북 서브페이지로 복귀.
- **브라우저 뒤로가기 제어 (`history.pushState`):** 뷰 전환 시 URL hash/state를 갱신하여 브라우저 뒤로가기 누름 시 [상세 ➔ 룩북 ➔ 메인] 순으로 자연스럽게 복귀할 것.
